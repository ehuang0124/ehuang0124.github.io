Data Sync Agent

A secure, resumable path from customer SQL Server changes to cloud durability—made legible through a 13-step interactive system walkthrough.

Open the architecture + decisions

The challenge

Move a consistent baseline and every later change without gaps, protect customer rows across trust boundaries, and recover deterministically after a lost acknowledgment or outage.

System decisions

Correctness is designed into every handoff.

  • Capture the starting LSN before snapshot reads so concurrent changes never fall into a blind interval.
  • Encrypt each immutable batch and authenticate its metadata before it leaves the agent.
  • Treat the cloud cursor—not volatile agent memory—as the authority when reconciling retries.
  • Rebaseline only the affected table when required CDC history is no longer retained.
What it demonstratesEnd-to-end reasoning across enrollment, snapshot/CDC coordination, encryption, flow control, idempotency, audit, acknowledgment, and recovery.
