# 型錄 Icon Style Guide

此文件為網站版型規格書，**不渲染於網站上**，僅存在於 repo 中作為設計與實作依據。
網站端的「型錄」區塊為內容索引（只列各次旅行特輯），樣式規範統一寫在此。

---

## 2. Icon 設計規範

### 2.1 格線與筆觸

| 項目 | 值 |
| ---- | -- |
| 格線 | **24 × 24** px viewBox（`0 0 24 24`） |
| 筆觸寬 | **1.5** px（與菱格紋 `an-lattice` 同寬） |
| 端點 | `stroke-linecap: round`（視語意可選，但全組需一致） |
| 轉角 | `stroke-linejoin: round` |
| 填色 | **不填色**（`fill: none`），統一使用外框線；實心圓/點僅作為筆觸細節，不大面積鋪面 |
| 顏色 | 一律透過 `currentColor` 繼承，不在 symbol 內寫死色碼 |

### 2.2 現有 icon 清單

sprite 檔案：`personal/travel/assets/travel-icons.svg`。
參考語法：
```html
<svg class="an-i" aria-hidden="true"><use href="/personal/travel/assets/travel-icons.svg#an-castle"/></svg>
```

### 2.3 裝飾性圖紋

| ID | 尺寸 | 用途 |
| -- | ---- | ---- |
| `an-lattice` | 240 × 24 viewBox | 長崎觀光品牌的菱格鏈紋；**僅用於**分區隔線（hero 下方、青島 band、footer 上方、型錄標題區），不作為一般 icon 使用、不鋪滿大面積背景 |

使用菱格紋時筆觸寬與 icon 同為 1.5，顏色同樣由 `currentColor` 繼承（常套 `--ng-line` 或 `--ng-red`）。

### 2.4 新增 icon 流程

1. 確認主題沒有既有的 12 個 icon 涵蓋；
2. 在 `travel-icons.svg` 內新增 `<symbol id="an-{name}" viewBox="0 0 24 24">`；
3. 路徑以 24px 格線、1.5 筆觸、無填色繪製，保留至少 2px 的視覺邊距；
4. 在本文件 §2.2 表格補上 ID、中文名與用途；
5. 在網站端引用時一律透過 `<use href="…#an-{name}"/>`，不直接 inline path。

## 3. 色彩系統

落地頁（長崎品牌）使用 `--ng-*` token；行程頁使用 `--mag-*` token。型錄使用的 icon 在兩個頁面皆透過 `currentColor` 吃文字色，不直接指定色票。

### 長崎品牌（landing）色票

| Token | 色碼 | 名前 | 用途 |
| ----- | ---- | ---- | ---- |
| `--ng-white` | `#FFFFFF` | 白 | 主背景 |
| `--ng-paper` | `#F6F5F1` | 生成り | 次背景／panel |
| `--ng-ink` | `#1C1C1C` | 墨 | 主文字 |
| `--ng-red` | `#C9202F` | 長崎レッド | 主強調色（連結、chip、icon 預設色） |
| `--ng-red-dark` | `#A3162A` | 茜 | 深色強調（hover、postmark） |
| `--ng-navy` | `#12314B` | 長崎藍 | 差し色（不鋪面） |
| `--ng-gold` | `#C2A05C` | 金茶 | 差し色（琉球／沖繩 accent） |
| `--ng-line` | `#E2E0D8` | 罫線 | 分隔線、格子線 |

組版原則：白・生成り為地，墨・長崎レッド為骨架，藍・金茶只作差し色，不填滿大面積。

### 旅行特輯分類色

| 特輯 | 色 | token |
| ---- | -- | ----- |
| 東日本（東海道） | 長崎藍 | `--ng-navy` `#12314B` |
| 九州 | 長崎レッド | `--ng-red` `#C9202F` |
| 沖繩 | 金茶 | `--ng-gold` `#C2A05C` |

## 4. 字體與級數

| 角色 | 級數 | 行高 | 字距 | 字體 |
| ---- | ---- | ---- | ---- | ---- |
| Headline（刊物名） | 58 | 1.10 | –0.01em | Noto Sans JP/TC 900 |
| Subhead（區塊標題） | 36 | 1.30 | 0 | Noto Sans JP/TC 900 |
| Body | 14 | 1.90 | 0.02em | Noto Sans JP/TC 400–500 |
| Label／拉丁小標 | 9 | – | 0.26em | Archivo 700, uppercase |

- 落地頁全頁ゴシック（Noto Sans JP/TC + Archivo）；**不使用明朝體**。
- 級數與實作以 CSS 變數為準，不在 HTML 寫死 px。

## 5. 型錄區塊版型原則（供前端實作對照）

1. **照片、期號、標題、路線、連結**五個要素必備；
2. 每個特輯是一組左右交錯的編排（`ng-lead`）：照片與文案在相鄰條目間換邊，外框以 1px 分類色偏移成「印版」錯位效果，期號以大型空心字壓在照片左下／右下，縱書期號標籤（第 0X 號）貼在照片左上；
3. 旅行特輯的標題句型統一為「{地區}的{主題}之旅」（參 §1）；
4. 每個特輯的副文案必須從該次旅行頁面的 H1、縱書 rail 或 meta description 裡擷取關鍵字，不另外憑空創作主題；
5. 分類色依 §3.2 對應該次旅行，icon 以該次旅程代表性 2–3 個為限（參卡片上的 ng-card-chips），不堆砌；
6. 圓角 8–16 px；1px 罫線；除明信片浮起外不使用陰影；
7. 菱格紋只放在區塊標題兩側或區塊之間作為分隔，不在列舉項內重複出現。

## 6. 禁止事項

- ❌ 在此文件以外的地方（網站 HTML/CSS）編寫獨立的 icon 色碼或線寬；一律以這裡的 token 與規則為準。
- ❌ 將填色實心 icon 混入本組線稿；如需新實心 icon，先確認是否真的需要偏離現有風格。
- ❌ 把菱格紋拿來做大面積背景或按鈕底紋；僅限分隔用途。
- ❌ 型錄條目順序調換時**跳過 §1 規則**——特輯永遠依行程日期序。
- ❌ 在型錄內重新加入「世界蓋章」條目——它不屬於型錄目次。
- ❌ 為旅行特輯撰寫偏離 H1／縱書的新主題名稱；文案必須從原頁標題抽取出來。
