# 日本茶風味診斷 · Japanese Tea Finder

`/personal/tea-quiz/` — 不用註冊的日本茶選茶 Quiz。新版 7 題從聞香、第一口、茶湯份量、餘韻、喝法、飲用時刻與咖啡因需求出發，給出 3 款可解釋的推薦。

原規格來源為 Notion《Japanese Tea Finder｜選茶 Quiz 網站產品與技術規格》；本版依使用者要求重新設計題目與和紅茶結果，以下規則以目前程式為準。

## 檔案

| 檔案 | 內容 |
| --- | --- |
| `index.html` | 頁面骨架、語言切換、麵包屑、詳情 dialog。 |
| `tea.css` | 米紙底、抹茶綠、茶湯金；非對稱照片拼貼、產地遮罩、手機選項排版。 |
| `assets/` | 3 張真實茶園／茶葉照片（WebP），來源與授權見 `CREDITS.md`。 |
| `drinks/` | 八個茶類的茶湯插畫（水彩、同一套語彙），結果卡牌與茶款詳情使用。 |
| `data.js` | 18 款茶，包含 6 款和紅茶；產地、品種、編輯風味標籤、咖啡因與來源。 |
| `quiz.js` | 新版 7 題、偏好向量、確定性評分、依喝法生成的沖泡句、v2 分享編碼。 |
| `app.js` | 首頁（CTA 在最上面）、Quiz、結果卡牌與一列導覽、茶款詳情、目錄；繁中／EN。 |

沒有建置流程、執行依賴或後端。GitHub Pages 直接載入 ES modules；字體離線時退回系統字體。

## 首頁：CTA 在最上面

標題與一句話說明之後就是「開始選茶」大按鈕，排在照片拼貼之前：一進頁面不必捲動就看得到、按得到。按鈕 60px 高、抹茶綠漸層、hover 時整顆上浮且箭頭往前；右邊是三杯茶湯插畫的圓形預告（裝飾用、`alt=""`，手機版移到按鈕下方置中），再下面才是「直接探索茶種」的安靜連結。依 `skill.md`，CTA 不加「7 題・2 分鐘・免註冊」這類 Quiz metadata，也不加標語，吸引力由按鈕本身與茶湯預告承擔。

## 新版題目

1. 聞香：嫩葉／花果／蜜香／炒焙／麥芽可可。
2. 第一口：清甜／鮮味／果蜜／焙炒／均衡。
3. 茶湯份量：輕盈／圓潤／稠滑／厚實。
4. 餘韻：柔和／一點收斂／明顯俐落。
5. 喝法：日常熱泡／細細品飲／冷泡／奶茶／茶筅抹茶。
6. 時刻：早餐／午後點心／晚上閱讀／隨時（可跳過）。
7. 咖啡因：一般／盡量少／只選明確標示無咖啡因商品（可跳過）。

每個選項附日常描述，不再用抽象符號代替味道。必答題未選不能前進；跳過可選題會清除該題答案。

## 結果頁：一次一張卡牌

結果不是一長條頁面，是一疊三張卡牌，一次看一張。

- **不捲動**：結果頁和 Quiz 一樣固定在一個視窗高度內（`100dvh`），手機直式、橫式、平板與桌面都不必把頁面往下滑。
- **簡潔 navigation**：頁首只有一行（`你的風味輪廓` ＋ 輪廓名的 visible `h1`）與「風味偏好」chip，沒有操作說明句；頁尾一列 `← ／ 1 2 3 ／ →`。箭頭是 48px 圓鈕，`←`／`→` 鍵也能切換；走到第三張時「下一款」變成填色的「分享茶譜 ↗」。箭頭鈕與步進鈕的 `aria-label` 唸出要去的茶名，切換時 `role="status"` 播報「第 2 款，共 3 款：…」。
- **卡面**：茶類的飲品插畫、序號與角色徽章（最推薦／相似路線／另一種相近風格／探索推薦）、茶名與日文名、**這款茶以什麼聞名的一句話**、**產地小地圖**、風味標籤、「完整資訊」與沖泡比例摘要。品種、香氣家族、咖啡因細節、完整沖泡與喝法建議、購買日文、完整產地圖與資料來源都在「完整資訊」詳情層。
- **不解釋推薦原因**：卡面與詳情層都不列「因為你選了…」的貼近理由或分數對照。`data.js` 的 `knownForZh／knownForEn` 只講產地與茶本身的名聲（單句），評分邏輯仍是確定性的，只是不再說服使用者。
- **產地小地圖**：40 × 46 的日本輪廓加產地圓點，右邊是產地、茶類、咖啡因狀態與「位置為概略」。縮圖之後海岸線改用 `non-scaling-stroke`、圓點半徑放大才看得到；`role="img"` 的替代文字唸出完整產地與概略位置說明。完整大小的產地圖留在詳情層。
- **偏好與出口**：「風味偏好」開啟偏好雷達、修改答案、重新測驗、分享與茶款目錄（不再放卡牌角色說明）。
- 視窗高度不夠時，只有卡牌內容會內部捲動，導覽列一定留在畫面上；`max-height` 斷點依序收掉風味標籤、插畫高度與麵包屑，「以什麼聞名」與產地小地圖一定留著。

插畫畫的是**茶類的茶湯**，不是某一支商品的實拍照；卡牌上的圖只用來認茶類，不當成產品型錄。

## 無障礙

Quiz 與結果頁都固定在一個視窗高度內，手機直式、橫式與 320px 寬都不必捲動；選項本身就是按鈕（不畫 radio 圓點，選取狀態用填色、邊框與 ✓ 表示）。觸控目標 ≥ 44px、`Focus-visible` 可見、顏色不是唯一的資訊來源（風味一律附數字 0–5 與文字標籤）、`prefers-reduced-motion` 會關掉轉場、320px 寬不出現水平捲動、Quiz 與結果卡牌都可用鍵盤（←/→、Tab、Enter）操作，切換卡牌不會把焦點丟回頁首；咖啡因與沖泡資訊都是純文字表格。

## 推薦引擎

- 七維向量：`body / viscosity / umami / sweetness / astringency / roast / aroma`，未回答為 3。
- 權重：香氣 25%、滋味 25%、口感 20%、餘韻 15%、喝法與時刻 15%。香氣同時比對氣味家族，不只看強度。
- 明確選奶茶時，優先在 6 款和紅茶內比較，不再硬塞一款綠茶作為「多樣性」。其他喝法保留第三款跨茶類探索。
- 無咖啡因是硬過濾；「盡量少」只是軟性偏好，不把未知數值當成零，也不拿玉露濃縮參考值與一般茶湯直接比較。
- 不輸出推薦理由：`buildReasons` 與分數對照句已整段移除。唯一與答案有關的句子是 `methodNote` —— 依選定喝法與這款茶實際比例生成的沖泡句，放在「完整資訊」的建議沖泡裡。
- 同答案同結果。分享碼為 `v2.1311121` 形式；舊版七碼不重映射，無效或缺必答題的連結回首頁，不拿目前工作階段答案冒充分享結果。

## 資料與授權規則

- 風味 0–5 是編輯標籤，不是化驗值或個人化預測。
- 咖啡因狀態與類別參考值分開；沒有同產品、同條件實測就不顯示產品 mg 數字。
- 只有包裝明確標示無咖啡因的商品可作嚴格推薦；焙茶、玄米茶、冠茶、玉露與一般和紅茶都不算。
- 新增茶款連到生產者／茶商頁面及農林水產省參考資料。
- 每款都要有 `knownForZh／knownForEn`：一句話、只講這款茶（或這個產地）以什麼聞名，不寫推薦理由。
- 照片授權與改作記錄在 `assets/CREDITS.md`，頁面也保留簡短署名。
