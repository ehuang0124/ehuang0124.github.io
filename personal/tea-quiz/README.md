# 日本茶風味診斷 · Japanese Tea Finder

`/personal/tea-quiz/` — 一個不用註冊的日本茶選茶 Quiz。7 題問口感、鮮味、澀度、香氣、咖啡因與泡法，給出 3 款可解釋的推薦（茶種、產地、日文名、推薦原因、風味標籤、咖啡因標示、沖泡比例、購買關鍵字）。

規格來源：Notion《Japanese Tea Finder｜選茶 Quiz 網站產品與技術規格》。本目錄是該規格的 MVP 實作。

## 推薦引擎（可解釋、確定性）

1. **硬過濾** — Q5 選「必須無咖啡因」時只留 `caffeine.status === 'verified_free'`。沒有符合商品就顯示空狀態，不放寬條件，也不拿焙茶／玄米茶充數。
2. **偏好向量** — 七個維度 `body / viscosity / umami / sweetness / astringency / roast / aroma`，各 0–5，未問到的維度保持 3（中性）。
3. **加權相似度** — 口感與稠滑 30%、甘甜鮮味 25%、澀度 20%、香氣 10%、泡法與情境 15%。「盡量少咖啡因」只是軟性降權。
4. **多樣性** — Top 3 不全部同茶類；若前三名同類，保留第一、第二，第三換成另一風格中最高分者並標示「探索推薦」。
5. **解釋** — 每張卡固定兩條「你的答案 → 這款的標籤」句子（來自不同題目），再加一條泡法。不把演算法說成化學分析。

同樣的答案永遠得到同樣的結果；`#/result/3411321` 這種分享碼就是七題的選項序號，不含任何個人資料。壞掉的分享碼會回首頁，不會假裝有結果。

規格 §5 的範例使用者（微稠、清甜＋鮮味、幾乎不澀、低調香氣、咖啡因一般、全天、日常泡）得到 **伊勢冠茶 → 嬉野蒸製玉綠茶 → 知覽深蒸さえみどり**，與規格預期一致。

## 資料規則（改資料前必讀）

- `taste` 的 0–5 分是**編輯標籤／產品設計假設**，不是化驗值，也不是個人化預測；上線前需以品飲或茶商資料校準。
- 咖啡因沒有「同產品、同沖泡條件」的實測值時，`caffeine.mgPer100ml` 一律 `null`，介面顯示「含咖啡因 · 數值未知」與類別參考值，**不換算成每杯攝取量**。
- 只有包裝明確標示 `ノンカフェイン／カフェインレス` 的商品可以是 `verified_free`。玄米茶、焙茶、冠茶、玉露都不是。
- 玉露的 160 mg／100 mL 是 10 g 茶葉對 60 mL 水，與其他茶類不能同容量比較；抹茶以粉量計，不是浸出液。
- 每筆資料都要有可追溯來源。產地知名不代表每款茶品質一致。

參考：[農林水產省「食品中のカフェイン」](https://www.maff.go.jp/j/syouan/seisaku/risk_analysis/priority/hazard_chem/caffeine.html)

## 無障礙

觸控目標 ≥ 44px、`Focus-visible` 可見、顏色不是唯一的資訊來源（風味一律附數字 0–5 與文字標籤）、`prefers-reduced-motion` 會關掉轉場、320px 寬不出現水平捲動、Quiz 可用鍵盤（←/→、Tab、Enter）操作，咖啡因與沖泡資訊都是純文字表格。
