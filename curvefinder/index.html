Honest scope

This demo starts after a road centerline has been extracted from a LiDAR point cloud. Production point-cloud classification and centerline extraction are separate preprocessing steps.

Method

Small, inspectable geometry.

  1. OrderSort projected centerline points by station_m.
  2. MeasureEstimate signed Menger curvature across a configurable window.
  3. ClassifyConvert curvature to radius and mark straight, gentle, moderate, and tight segments.
  4. PublishExport a GeoJSON line layer or run the included ArcGIS Pro toolbox.

ArcGIS Pro toolbox

The demo has a GIS handoff.

The included Python toolbox accepts a projected point layer with a station_m field and creates classified line features with curvature, radius, and turn direction.
